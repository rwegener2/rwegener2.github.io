					<h3>icepyx</h3>
				</header>
				<p>The <a href="https://github.com/icesat2py/icepyx">icepyx library</a> is a Python package for searching, accessing, and working with data from NASA’s <a href="https://icesat-2.gsfc.nasa.gov/"> ICESat-2 (Ice, Cloud, and Land Elevation Satellite-2) </a> satellite lidar. This impactful package enables scientific researchers to more quickly and efficiently process their data and focus on analysis. In development since 2019, the package has over 40 contributors and over 250 Github stars. As part of this project I have worked primarily on cloud data access. I designed and implemented the cloud module and I continue to work collaboratively with team members across the ICESat-2 mission to improve the performance of cloud access with icepyx. <br>
				Check out some things I've been involved with on behalf of icepyx:</p>
				<ul>
					<li>Virtual presentation at the <a href="https://eo4sdg.org/space-and-sustainability-colloquium/">International Colloquium for Space and Sustainability</a></li>
					<li>CSCCE’s Open Source Governance and <a href="https://www.cscce.org/trainings/pbk/">Creating Community Playbooks</a></li>
					<li>10 Simple Rules for Improving the Usability of Earth Observation Mission Datasets (<a href="https://doi.org/10.22541/essoar.176892205.56393151/v1">preprint</a>) </li>

				<p>The <a href="https://joss.theoj.org/"> Journal of Open Source Software </a> is an open source journal publication for research software. The journal has over 6,000 articles and pioneers an entirely open Github-based review process (<a href="https://doi.org/10.31274/jlsc.18285">read more about it!</a>). I have been an editor overseeing software submissions in the Earth Science and Ecology track since January 2024.</p>
